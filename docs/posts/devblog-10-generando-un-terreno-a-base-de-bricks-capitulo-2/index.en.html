If we generate the world now we get this:

A world of bricks, but with a few problems:
- There are gaps between the bricks
- If you look at the bottom right of the image, you'll see the sides of the bricks aren't being rendered
- Some triangles are broken/out of place

The first bug is because the matrix we created is based on integers and the brick dimensions aren't integers.
If we multiply the placement position by the brick's width / height, we'll get the adjusted position.

The second bug is because of how I assigned each face. I was following the top|bottom|left|right|front|back logic. But that's not really how it works, instead we start with face 0, then 1, 2...Long story short, it gets fixed by tweaking the FaceMapper I made.

As for the third bug........ I have no fucking idea why it happens. I did check that if I cut the top face higher up, so that there are only studs, everything renders fine. So there's some problem with the model:
