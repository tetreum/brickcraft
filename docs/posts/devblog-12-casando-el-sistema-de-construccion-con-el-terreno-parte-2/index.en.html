Picking up where we left off: The building system detects collisions with the terrain constantly.


(Red means it won't let you build, white means it will).


As I mentioned, there can be 2 types of collisions, vertical ones which are "expected" (since the brick bumps into another brick's studs) and horizontal ones, which are real collisions since they happen when the models go through each other.
To fix something like that we'd have to check all the intersection points between the 2 objects and discard the vertical ones. But we'd be trying to fix a problem that comes from another problem.

The real problem is that to generate each chunk's collider, I'm using the mesh that gets displayed. That means Unity takes the bricks' studs into account, making it a hell of an expensive operation, and an unwanted one too.

As painful to generate as it looks.
If you remember, our bricks' GridStuds are box colliders:


(the green stuff)
At no point do we take the shape of the studs into account, we don't care. And we should do the same with the terrain.
How are we going to do it? By creating a neeew model that's a plain old cube. We grab the brick and remove the studs and the bottom part. That way it has the same measurements, but it's a cube.

And now we have to edit the chunk generation, so that 2 meshes get created, 1 that takes the studs into account and another that doesn't.

It's almost all copy&paste of what we already had, we just have to remove the uvs and colors part since we don't care about it.
We try generating the terrain and... Damn, what a difference in loading speed, it's not nearly as painful as before.

With this move we've achieved several things:
- Reduced loading times by simplifying the mesh used to generate the colliders
- No more vertical collisions.
- Improved the "walking". With the studs having collisions, it felt like you were walking through the hills, with mini-mountains all the time. Now, despite having shape, the terrain is flat to walk on.

Now that we don't have vertical collisions, the collision detection system should work without needing any edits.
