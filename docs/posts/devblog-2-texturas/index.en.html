Breaking blocks and block types

Now that I have an inventory system (although not with all the features I listed at the start), I'll probably start adding color to the blocks, making them imply a different type just like in minecraft. That is, brown would be dirt and take less time to remove than a metal one, for example.


Checking how minecraft does it (https://minecraft.gamepedia.com/Breaking), they give each block a value called "hardness", which goes from 0 to 100. And depending on that value and the tool in your hand, it takes more or less time to mine the blocks.


Once again I couldn't be bothered, so instead of using that same scale, I created a hardness value for each brick, which is directly the number of seconds it takes to mine it by hand. If the game ever gets tools, I'd just knock some seconds off.

Revisiting the building system

After this I couldn't help building a little house and............. it turned out awful.


The pattern of 1 stud of space between brick and brick wasn't on purpose, it just flat out wouldn't let me put anything there. It also seems that, depending on how, it adds a lot of space between stacked blocks, enough to be noticeable and look bad :S
Dammit, we're back to the foundation of the game, the building system.


I think the first problem is because the blocks fill their space perfectly, so they touch each other and the system detects it as a collision.


Megazoom of 2 bricks to show the problem visually.

- One hack would be to tweak the blocks' collider so it's slightly smaller than the model.
- Another hack would be to make the preview's scale smaller than the final model.
- And the proper way (I guess) would be, when detecting a collision, to check what % of the surface is inside the other block and discard the ones that go in less than 1%.

Obviously the proper way involves doing calculations and blah blah blah, so I'll do the second hack and cross my fingers that it has no long-term consequences.
