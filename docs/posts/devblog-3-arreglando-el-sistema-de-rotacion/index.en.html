The calculations part couldn't fail anymore, so the screw-up was somewhere else and I suspected it was in the GridStuds. And so it was.
To set the size each GridStud took up, I edited the cube's scale instead of editing the collider's dimensions.
So that those of you who don't use Unity understand the mistake:
Every object in a scene has a component called Transform. The transform holds the location data, namely: position, rotation and scale.

Normally you don't touch the scale, but if you do, you have to keep in mind that you're altering all the vectors/positions you generate from it.
In the collider component you can tweak its dimensions:

So when you're adding collisions to an object via the collider, the normal thing is to tweak the collider's dimensions, not the object itself.
I had tweaked the scales, hence the offset from the center:
