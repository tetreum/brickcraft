Once we've generated the matrix comes the hardest part, rendering it.
We can't render the whole thing, no GPU could load that many bricks (and it would be a stupid idea), so we have to go with a chunk system.
This is nothing more than splitting the matrix into smaller matrices. That way we can load or unload them as the player moves around the map.

To cut a face out of a model we'll need to understand what a mesh/model is and how it works.

Understanding meshes

A mesh is a set of points (vertices) that, connected to each other, form triangles. To know which way each triangle is facing/painted we use vectors (normals) and finally we also map how the material (texture) is applied to the mesh.

In Unity we have the mesh data in the following format:
Code:

        int[] triangles;
        Vector3[] vertices;
Triangles are referenced through a list of integers, which only act as references to the vertex list.
Let me explain:
Code:
    int[] triangles would be a list like this: [0,1,2,2,3,0]
    Vector3[] vertices would be
    [
        0 => Vector3(0, 0, 0),
        1 => Vector3(0, 0, 1),
        2 => Vector3(1, 0, 1),
        3 => Vector3(1, 0, 0)
    ]
So you can picture it:

As we already know, each triangle is made of 3 vertices, so to get a triangle from the triangles list, we'll grab 3 values each time:
- The first triangle will be 0,1,2
- The second 2,3,0
These are just the indices to take from the vertex list, so now we know that the first triangle, the one on the left, is made of the vertices:
0 => Vector3(0, 0, 0)
1 => Vector3(0, 0, 1)
2 => Vector3(1, 0, 1)
And the second:
2 => Vector3(1, 0, 1)
3 => Vector3(1, 0, 0)
0 => Vector3(0, 0, 0)
