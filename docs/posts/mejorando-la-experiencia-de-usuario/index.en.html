Improving the user experience

I often complain about how bad the user experience is when you come back to a game you haven't touched in years.
You have to rediscover the keys and the mechanics because the game makes no effort at all to offer you a tutorial to refresh your memory.

To keep that from happening in Brickcraft, there are now several tutorials that walk the player, step by step, through building a house and a car.

Also, while you're building, the bottom right of the screen shows the keys that may come in handy at each moment:

And to wrap up, lots of people still don't speak English these days. So I've added support for multiple languages.

Paving the way for vehicles

Lego bricks don't only have studs as their connector/anchoring system.
There are also grooves:

(Those little slots that let you put glass in windows).

And the holes axles go into:

To be able to build vehicles, we had to start supporting these connectors. Since axle-related bricks usually have several holes, there's now an option to jump to the next connector, as well as to slide the axle along it.

Along the way it became clear that building vehicles was quite tricky, because blocks are always centred wherever the player is looking. If, for example, you want to put a base on your car, half of it would usually go right through the nearest wheel.
So there's now a key that moves the centring to one of the block's sides.

After crashing my first car, it was obvious there had to be a way to reposition the vehicle, which has been added as the /reposition chat command.

There's more new stuff in this update, but these are the most relevant changes.
